# Plan 06-02: API Clients + Token Management

**Wave 1 — Platform Clients**

## Goal

Build custom TypeScript HTTP clients for Shopee and TikTok Shop with HMAC signing, and implement OAuth token storage + auto-refresh via BullMQ.

## Tasks

### Task 1: Shared Marketplace Client Infrastructure

Create `apps/api/src/modules/marketplace/lib/`:

**`hmac.ts`** — Platform-agnostic HMAC-SHA256 helper
- `signShopee(partnerKey, path, timestamp, accessToken, shopId)` → hex string
- `signTiktok(appSecret, path, timestamp, params)` → hex string
- Unit tests for both with known test vectors

**`shopee-client.ts`** — Shopee HTTP client
- Base URL: `https://partner.shopeemobile.com` (prod) / `partner.test-stable.shopeemobile.com` (sandbox)
- Auto-inject: `partner_id`, `timestamp`, `sign`, `access_token`, `shop_id`
- Methods: `get(path, params)`, `post(path, body)`
- Retry with exponential backoff on 429
- Configurable timeout (default 10s)

**`tiktok-client.ts`** — TikTok Shop HTTP client
- Base URL: `https://open-api.tiktokglobalshop.com` (prod)
- Auto-inject: `app_key`, `timestamp`, `sign`, `access_token`, `shop_cipher`
- API versioning support (default `202309`)
- Methods: `get(path, params)`, `post(path, body)`
- Retry with exponential backoff on 429

### Task 2: Token Management Service + Refresh Worker

**`token.service.ts`:**
- `getToken(platform, shopId)` → token record or null
- `upsertToken(platform, shopId, tokenData)` → saved token
- `getExpiringTokens(withinMinutes)` → tokens expiring soon
- `refreshShopeeToken(tokenRecord)` → calls Shopee refresh endpoint, updates DB
- `refreshTiktokToken(tokenRecord)` → calls TikTok refresh endpoint, updates DB

**`token-refresh.worker.ts`:**
- BullMQ repeatable job: every 30 minutes
- Fetches tokens expiring within 60 minutes
- Attempts refresh; on 2x consecutive failure, enqueue alert to low-stock notification channel
- Logs success/failure per token

**Tests:**
- Token CRUD: upsert, get, get-expiring
- Shopee refresh: mock HTTP, verify new tokens saved
- TikTok refresh: mock HTTP, verify new tokens saved
- Consecutive failure alert: verify notification enqueued after 2 failures
