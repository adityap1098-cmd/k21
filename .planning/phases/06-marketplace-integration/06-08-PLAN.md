# Plan 06-08: Marketplace API Endpoints + OAuth Flow

**Wave 5 — Wire Everything Together**

## Goal

Replace stub marketplace router with real endpoints: OAuth authorization, channel management, order listing, listing CRUD, webhook event log.

## Tasks

### Task 1: OAuth Flow Endpoints

Update `apps/api/src/modules/marketplace/marketplace.router.ts`:

**Shopee OAuth:**
- `POST /channels/shopee/authorize` → generate Shopee auth URL with partner_id, redirect_url, timestamp, sign → return URL for frontend redirect
- `GET /channels/shopee/callback` → receive `code` + `shop_id` from Shopee redirect → exchange for access_token + refresh_token → store in marketplace_tokens

**TikTok OAuth:**
- `POST /channels/tiktok/authorize` → generate TikTok auth URL → return URL
- `GET /channels/tiktok/callback` → receive `code` → exchange for tokens → store + fetch authorized shop list → store shop_cipher

### Task 2: Channel Management Endpoints

- `GET /channels` → list marketplace_tokens (mask actual token values, show platform, shopName, status, expiry)
- `POST /channels/:id/disconnect` → soft-delete token record
- `POST /channels/:id/reconnect` → re-initiate OAuth

### Task 3: Marketplace Listing CRUD

- `GET /listings` → list marketplace_listings with variant info
- `POST /listings` → create mapping: `{ platform, platformItemId, platformModelId, variantId }`
- `DELETE /listings/:id` → remove mapping
- `POST /listings/sync-all` → enqueue stock sync for all SYNCED listings

### Task 4: Order & Webhook Endpoints (real data)

- `GET /orders` → list marketplace_orders with pagination/filters (platform, status, date range)
- `GET /orders/:id` → order detail with items
- `GET /webhooks` → list webhook_events (recent, paginated) for debugging

### Task 5: Tests

- OAuth flow: authorize returns valid URL, callback stores tokens
- Channel list: returns channels with masked tokens
- Disconnect: marks token inactive
- Listing CRUD: create, list, delete
- Order list: returns paginated orders with correct filters
