# Plan 06-04: Order Import Workers

**Wave 3 — Order Processing**

## Goal

BullMQ workers that process webhook events into marketplace_orders, map items to K21 variants, and create stock reservations.

## Tasks

### Task 1: Order Import Worker

Create `apps/api/src/modules/marketplace/workers/order-import.worker.ts`:

**`marketplace.process-webhook` job handler:**
1. Load webhook_event by ID → mark PROCESSING
2. Parse rawPayload based on platform
3. For order events:
   a. Normalize payload → common `MarketplaceOrderData` shape
   b. Upsert `marketplace_orders` (ON CONFLICT platform+platformOrderId → update status)
   c. For each item: lookup `marketplace_listings` by `(platform, platformItemId, platformModelId)` → get `variantId`
   d. Insert `marketplace_order_items`
   e. If status = CONFIRMED/READY_TO_SHIP: call `reserveStock(variantId, qty)` for each mapped item
   f. If any item unmapped (no variantId): enqueue alert notification
4. Mark webhook_event as PROCESSED
5. On error: mark FAILED with error message, retry up to 3x

**`order.service.ts`:**
- `normalizeShopeeOrder(payload)` → `MarketplaceOrderData`
- `normalizeTiktokOrder(payload)` → `MarketplaceOrderData`
- `importMarketplaceOrder(data)` → creates order + items + reservations in one transaction
- `getMarketplaceOrder(id)` → order with items
- `listMarketplaceOrders(filters)` → paginated list with platform/status filters

**Types (`marketplace.types.ts`):**
```typescript
interface MarketplaceOrderData {
  platform: 'SHOPEE' | 'TIKTOK'
  platformOrderId: string
  platformOrderSn?: string
  status: MarketplaceOrderStatus
  buyerUsername?: string
  shippingAddress?: Record<string, unknown>
  orderTotal: number
  platformFees?: number
  platformData?: Record<string, unknown>
  items: MarketplaceOrderItemData[]
}
```

### Task 2: Tests

- Shopee order import: valid payload → order + items + reservation created
- TikTok order import: valid payload → order + items + reservation created
- Unmapped SKU: item created with variantId=null, alert enqueued

- Webhook status transitions: RECEIVED → PROCESSING → PROCESSED
