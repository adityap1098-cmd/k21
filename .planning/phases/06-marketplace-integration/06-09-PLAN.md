# Plan 06-09: Marketplace Frontend

**Wave 6 — UI**

## Goal

Build the marketplace management UI: channel connection, order view, SKU mapping, webhook log.

## Tasks

### Task 1: Channel Connection UI

Update `apps/web/src/app/marketplace/page.tsx`:
- Replace hardcoded channels with `apiGet('/api/v1/marketplace/channels')`
- "Tambah Channel" button → modal with Shopee/TikTok selection → calls `/authorize` → redirects to platform
- Channel cards show real status, token expiry countdown
- "Disconnect" button with confirmation dialog
- Token health indicator: green (>24h), amber (<24h), red (expired)

### Task 2: Marketplace Orders Tab

- Fetch from `apiGet('/api/v1/marketplace/orders')`
- Table: platform badge, order ID, buyer, items summary, total, status badge, date
- Filter by: platform (all/Shopee/TikTok), status, date range
- Click row → order detail panel/page showing items, shipping info, timeline

### Task 3: SKU Mapping Page

Create `apps/web/src/app/marketplace/listings/page.tsx`:
- Table of marketplace_listings with: platform, platform item ID, K21 variant (with product name)
- "Tambah Mapping" button → form: select platform, enter platform item/model ID, pick K21 variant (searchable dropdown from products API)
- Delete mapping with confirmation
- "Sync Semua Stok" button → calls `/listings/sync-all`
- Sync status column: SYNCED (green), PENDING (amber), FAILED (red)

### Task 4: Webhook Events Tab

- Fetch from `apiGet('/api/v1/marketplace/webhooks')`
- Table: timestamp, platform, event type, status (PROCESSED/FAILED), event ID
- Click row → expand to show raw payload (JSON viewer)
- Filter by status (all/processed/failed)
- Useful for debugging when orders don't appear

## Verification

- All pages render without errors
- Channel connect flow navigates correctly
- Orders tab shows data from API
- SKU mapping CRUD works end-to-end
- Responsive layout on desktop and tablet
