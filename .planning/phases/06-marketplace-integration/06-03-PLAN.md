# Plan 06-03: Webhook Handlers

**Wave 2 — Webhook Ingestion Layer**

## Goal

Build thin webhook endpoints that validate HMAC, store raw payloads, deduplicate, and enqueue BullMQ jobs. No business logic in handlers.

## Tasks

### Task 1: Webhook Router + HMAC Middleware

Create `apps/api/src/modules/marketplace/webhook.router.ts`:

**`POST /api/v1/webhooks/shopee`** (no auth middleware — Shopee calls this directly)
1. Read raw body as buffer (needed for HMAC — must use `express.raw()` or equivalent)
2. Verify `x-shopee-signature` header using `signShopee(partnerKey, url, body)`
3. If invalid → 401
4. Parse JSON body → extract `event_type` (e.g. `order_status_push`) and derive `event_id` from payload
5. INSERT INTO `webhook_events` with `ON CONFLICT (platform, event_type, event_id) DO NOTHING`
6. If inserted (not duplicate): enqueue BullMQ job `marketplace.process-webhook` with `{ webhookEventId }`
7. If duplicate: log skip, still return 200
8. Return 200 immediately

**`POST /api/v1/webhooks/tiktok`** — same pattern, different HMAC verification

**Important:** Raw body parsing needs careful Express middleware config — `express.json()` consumes the body before HMAC can verify. Solution: use `express.raw({ type: 'application/json' })` on webhook routes only, or buffer the raw body via a custom middleware.

Wire webhook routes in `apps/api/src/index.ts` **before** `express.json()` middleware, or mount with route-specific raw parser.

### Task 2: Webhook Event Service + Tests

**`webhook.service.ts`:**
- `storeWebhookEvent(platform, eventType, eventId, rawPayload)` → { stored: boolean, id: string }
- `markProcessing(id)` → updates status
- `markProcessed(id)` → updates status + processedAt
- `markFailed(id, errorMessage)` → updates status + error + increments retryCount
- `getUnprocessedEvents(limit)` → for recovery/reprocessing

**Tests:**
- Store + dedup: insert same event twice, second returns `stored: false`
- HMAC validation: valid signature passes, tampered body fails
- Status transitions work correctly
- Full request test: POST to `/api/v1/webhooks/shopee` with valid HMAC → 200 + event stored
