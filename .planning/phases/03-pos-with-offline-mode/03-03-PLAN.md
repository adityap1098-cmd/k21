  <files>
    apps/api/src/modules/shifts/shifts.service.ts,

  </files>
  <behavior>
    - openShift({ cashierId, openingFloat }): checks for existing OPEN shift for this cashier via db.select; if found throws 'SHIFT_ALREADY_OPEN'; otherwise inserts new shift with status OPEN; returns new shift
    - closeShift({ shiftId, cashierId, closingCash }): verifies shift exists and is OPEN for this cashier; updates shift with status CLOSED, closingCash, closedAt = now(); calls getShiftReconciliation to compute and return reconciliation; throws SHIFT_NOT_FOUND or SHIFT_NOT_OPEN
    - getActiveShift(cashierId: string): returns OPEN shift or null
    - getShiftReconciliation(shiftId: string): Promise<ShiftReconciliation> — queries transaction_payments joined with transactions for this shift where status = 'COMPLETED'; aggregates totals per payment method; computes expectedCash = openingFloat + salesByCash; computes discrepancy = actualCash - expectedCash (null when shift still open)
  </behavior>
  <action>
    Create apps/api/src/modules/shifts/shifts.service.ts.

    Import: db from '../../db/index.js', { shifts, transactions, transactionPayments } from '../../db/schema/pos.js', { eq, and, sum, sql } from 'drizzle-orm', { randomUUID } from 'crypto'.

    openShift: use db.select().from(shifts).where(and(eq(shifts.cashierId, cashierId), eq(shifts.status, 'OPEN'))).limit(1) to check for existing open shift.

    closeShift: update shifts table with db.update(shifts).set({ status: 'CLOSED', closingCash, closedAt: new Date() }).where(and(eq(shifts.id, shiftId), eq(shifts.cashierId, cashierId), eq(shifts.status, 'OPEN'))).returning(); if returning() is empty, throw SHIFT_NOT_FOUND or SHIFT_NOT_OPEN.

    getShiftReconciliation: join query — select sum of amount grouped by method from transaction_payments where transactionId IN (SELECT id FROM transactions WHERE shift_id = shiftId AND status = 'COMPLETED'). Aggregate the result map into salesByCash, salesByTransfer, salesByQris. Compute totals.

    Create apps/api/src/modules/shifts/index.ts:
    ```typescript
    export * from './shifts.service.js'
    export * from './shifts.router.js'
    ```
    (router will be created in Task 2)
  </action>
