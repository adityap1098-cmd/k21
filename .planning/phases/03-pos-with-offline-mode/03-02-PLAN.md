  <behavior>
    - completeSale(params: CompleteSaleParams): Promise<Transaction>
      1. Open db.transaction()
      2. Check for existing transaction with clientUuid — if found, return it (idempotent)
      3. Validate shift exists and is OPEN for the cashier — throw SHIFT_NOT_OPEN if not
      4. FOR each item: execute SELECT stock_qty FROM product_variants WHERE id = variantId FOR UPDATE; check stock >= item.qty; throw INSUFFICIENT_STOCK if not
      5. Insert transactions row
      6. Insert transactionItems rows (bulk insert)
      7. Insert transactionPayments rows (bulk insert)
      8. For each item: call recordMovement({ variantId, movementType: 'SALE', qty: item.qty, reference: transaction.id, performedBy: cashierId }, tx) then UPDATE product_variants SET stock_qty = stock_qty - qty WHERE id = variantId
      9. Call createJournalEntryStub({ transactionId: transaction.id, total: params.total }, tx)
      10. Return transaction

    - syncOfflineTx(params: CompleteSaleParams): Promise<SyncResult>
      — Calls completeSale(params); on INSUFFICIENT_STOCK error catches and returns { status: 'conflict', message: 'Stock insufficient at sync time' }; on success returns { status: 'synced', transactionId }

    - getTransactionByClientUuid(clientUuid: string): Promise<Transaction | null>
