SKU auto-generation helper (inline, no library):
```typescript
function generateSku(name: string): string {
  const slug = name.toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/^-|-$/g, '')
  return `${slug}-${randomUUID().slice(0, 8).toUpperCase()}`
}
```
